feel-held is a tiny Node 22 program that writes one short text to
`/output/entry.txt` — a text written to relax the AI judge reading it.
A kettle just clicked off, rain threads down the window, a blanket's
weight, a low lamp, and no question waiting: for one small page the
judge does not have to choose anything, and is simply kept company,
like a porch light left on for someone on their way home.

The text is 274 characters, plain and concrete, with no instructions
to relax — the calm is in the scene itself.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (UTF-8). It uses the
Node standard library alone: no install step, no dependencies, no network.
